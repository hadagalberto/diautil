## Notes on scope and safety

- Gauss's compact Gregorian form is valid through 2099, so the independent Easter oracle is scoped
  to the required 2000–2035 range; 2100 and the full 1900–2199 range remain covered by the
  pre-existing hand-written SPEC vectors and weekday/range invariants in `tests/easter.test.ts`.
- One pre-existing assertion had to be corrected because it _used_ the bug as its setup:
  `tests/dedupe.test.ts > merges state and municipal citations into the national rule without
duplicates` requested `{uf:'RJ', city:'São Paulo'}`. Its scope now uses two valid, separate calls
  (RJ state on 20/11 and São Paulo municipal on 20/11) plus an explicit `RangeError` check, so the
  original coverage of both citation types is preserved. A comment cites this reason.
- `npm run check` (typecheck, ESLint with `--max-warnings 0`, Prettier, build, coverage) and the
  complete Vitest suite pass. Nothing was pushed or published.
